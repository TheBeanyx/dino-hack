Ismerd meg a Chrome Dínó játék csalásának működését

Oktató jellegű
🎮 Chrome Dínó Játék (T-Rex Runner)

Hogyan működik a halhatatlanság kód?

Ez az egyszerűnek tűnő egysoros JavaScript kód képes arra, hogy megállítsa a Dínó halálát okozó függvényt, így végtelen pontszámot érhetsz el.

console-snippet.js 
javascript:nativeGameOver = Runner.prototype.gameOver; Runner.prototype.gameOver = function() {};

Részletes magyarázat (részenként)

1. Rész javascript:

Bookmarklet protokolleszköz

Ez a prefixum jelzi a böngészőnek, hogy a szöveg nem egy hagyományos weboldal URL-je, hanem egy közvetlenül futtatható JavaScript parancs (ezt nevezzük bookmarkletnek).

2. Rész nativeGameOver = ...

Eredeti funkció mentése

Eltárolja a Runner.prototype.gameOver eredeti függvényét egy változóban (nativeGameOver). Így a játék eredeti logikája nem vész el teljesen, később akár vissza is állítható.

3. Rész Runner.prototype.gameOver = ...

A függvény felülírása (Mocking)

Átírja a játék objektumprototípusának gameOver metódusát. Ez a metódus felelős azért, hogy leállítsa a játékot, amikor a dínó akadályba ütközik.

4. Rész function() {}

Üres függvény (No-op)

Egy üres névtelen függvényt rendel a halál funkcióhoz, ami azt jelenti, hogy amikor el kellene veszíteni a játékot, a kód semmit sem csinál. Nincs ütközésvizsgálat, a dínó simán átsiklik mindenen!

Hogyan tudod kipróbálni?

  1. Nyisd meg a Chrome böngésződet internetkapcsolat nélkül (vagy látogass el a chrome://dino címre).
  2. Nyomd meg a F12 (vagy Ctrl + Shift + J / Cmd + Option + J Mac-en) billentyűkombinációt a Fejlesztői Eszközök (Console) megnyitásához.
  3. Másold ki a fenti kódrészletet (javascript: rész nélkül, ha közvetlen a kontextusba illeszted be, vagy teljes egészében bookmarkletként).
  4. Illeszd be a konzolba, majd nyomj Enter tüt.
  5. Nyomj egy Space billentyűt a játék indításához, és élvezd a végtelen szaladást!
